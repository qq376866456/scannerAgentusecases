# Agent 灵感库

参考 Agent Use Cases 的信息结构制作的独立中文案例目录，与原站没有官方关联。

## 启动

在项目目录执行 `node preview.cjs`，访问 http://127.0.0.1:8765 。页面文件位于 `dist/`，可以部署到静态网站服务。

## 功能与内容

- 中文搜索、场景与工具组合筛选、精选与添加顺序切换、加载更多。
- 案例详情、中文提示词复制（不可用时提供手动复制）、来源链接。
- 本地收藏、深色模式、自建灵感与删除；数据保存于浏览器 localStorage。
- 18 条初始内容：1 条带原帖的用户自述、1 条带原帖的方案参考、16 条原创练习模板。
- 响应式布局、键盘焦点、Esc 关闭弹窗、按 `/` 聚焦搜索。

现已支持独立采集 Hacker News 和公开 RSS/Atom，并通过 GitHub Actions 定时生成数据，再发布到 GitHub Pages，无需常驻服务器。部署与模型配置见 [DEPLOYMENT.md](DEPLOYMENT.md)。

网络线索与编辑精选分开展示。自动收录仅根据标题筛选，不能视为成功案例或效果验证。本站没有邮件订阅、后台审核或跨设备同步。所有中文提示词均重新编写，尚未实际执行验证。

## 文件

- `dist/index.html`：页面结构。
- `dist/style.css`：桌面、手机和深色样式。
- `dist/app.js`：内容数据及交互。
- `.github/workflows/refresh.yml`：定时采集与 GitHub Pages 发布。

字体使用 Google Fonts 的 Noto Sans SC；字体不可达时自动使用本机中文字体。

## 已完成的验证

浏览器验证了搜索、空结果、工具筛选、提示词复制、收藏刷新后保留、添加与删除本地灵感、深色切换，以及 390px 手机布局。验证时未捕获到浏览器脚本错误。JavaScript 语法检查通过。
